# 水保計畫輔助系統 — 下載與安裝

> 本頁只放安裝程式與更新套件。程式需要授權檔才能使用;安裝後請依畫面指示提供「裝置碼」給設計者取得授權。

## 下載

1. 點上方 **Releases**(或右側最新版本)。
2. 下載 **`SWCApp-win-Setup.exe`**(其他檔案是程式自動更新用的,不必下載)。

## 安裝

1. 雙擊 `SWCApp-win-Setup.exe`。**不需要管理員權限**,程式會裝到你自己的使用者資料夾。
2. 若 Windows 跳出「Windows 已保護您的電腦」(SmartScreen):點 **其他資訊 → 仍要執行**。
   這是未購買程式碼簽章憑證的正常現象,只在第一次安裝出現。
3. 安裝完成會自動開啟程式,桌面與開始功能表都有「水保計畫輔助系統」捷徑。
4. 第一次開啟會出現授權畫面:按 **複製裝置碼**,把裝置碼傳給設計者,收到授權檔(`*.swclic`)後按 **匯入授權檔**。

## 之後的更新

- 不用再回來這裡下載。程式開啟時會自動檢查新版本,標題列的版本號會亮一個小圓點;點開看更新內容,按 **立即更新** 即可(只下載有變動的部分)。
- 也可以在「關於」對話框按 **檢查更新**;在「設定」可以關閉自動檢查。

## 系統需求

- Windows 10(2018 年 4 月更新以後)或 Windows 11,64 位元。
- Microsoft Edge WebView2 Runtime(Windows 11 內建;缺少時程式會提示並開啟微軟下載頁)。
- DWG 匯入/匯出需要本機已安裝 AutoCAD 2013 以上(含 LT);沒有 AutoCAD 時以 DXF 匯入/匯出。

## 解除安裝

Windows 設定 → 應用程式 → 「水保計畫輔助系統」→ 解除安裝。授權檔與偏好設定會保留,重新安裝不必再申請授權。

## 舊版(單一 exe)使用者

直接安裝本版即可;舊的 exe 可以刪除。授權檔不必重新申請。專案存檔 `.swcproj` 照常開啟,新存檔為 `.swcp`。
